# Rivalry — Fantasy Esports Match Simulator

**Rivalry** is a browser-based fictional esports simulator for Overwatch 2, VALORANT, League of Legends, and Rocket League. Choose the teams, call tactics, or use spectator autoplay. The Overwatch team directory includes a curated **OWCS 2026 Stage 3** participant snapshot spanning EMEA, North America, Korea, Japan and China.

## Live website
After GitHub Pages is enabled, the expected address is:
**https://meowthebest.github.io/Rivalry/**

To publish: open repository **Settings → Pages** → under **Build and deployment**, select **Deploy from a branch** → **main**, **/(root)** → **Save**. GitHub will report the actual published URL when deployment completes.

## Run locally
No install or build step: open `index.html`, or run `python -m http.server 8000` and visit http://localhost:8000.

## Files
- `index.html`: main page
- `style.css`: responsive UI
- `teams.js`: OWCS Stage 3 participants, Overwatch maps, and hero composition presets
- `app.js`: fictional match engine, tactics, broadcast log, other esports, and history
- `favicon.svg`: Rivalry favicon

## Disclaimer
This is an unofficial fan project. It is not affiliated with Blizzard, Riot Games, Psyonix, OWCS, or professional esports teams. Outcomes are fictional and generated by a rules-based random simulator, **not real match results** or AI predictions. Participant names reflect a dated snapshot; they do not guarantee current player rosters, standings, or starting lineups. Match history is stored in your browser. Data sources are linked in `teams.js`.
